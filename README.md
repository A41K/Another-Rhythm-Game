So, this is as the name implies Another rhythm game made for the Remixed YSWS made in the GDScript
(This game is not like OTD), but its the second one.

The main object is to hit the notes with the circle that you move with the cursor. (i know its really simple).
You have a freeplay menu a settings menu and a skins menu
(i know its not a lot. I will write something bigger for the v1.0)
